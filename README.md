# Rotating Pipe / Dönen boru kesiti

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/rotating-pipe/).

Perspektif projeksiyonunda boru geometrisini döndür.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Boru yarıçapı
- Boru uzunluğu
- 8 saniyedeki dönüş

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Adjust pipe radius, length and rotation speed in a perspective preview.

Open [the live tool](https://omerbek.github.io/rotating-pipe/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
